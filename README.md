# 第三次作业 —— React 信息管理系统

## 作业要求

使用 React 制作一个**信息管理系统**，具体需求如下：

| 功能 | 说明 |
|------|------|
| 增加 | 通过表单输入信息（如姓名、年龄、邮箱等字段），点击添加按钮将信息加入列表 |
| 删除 | 每条信息提供删除按钮，点击后将该条信息从列表中移除 |
| 修改 | 每条信息提供编辑按钮，点击后可修改信息内容并保存 |
| 查询 | 提供搜索框，根据关键字过滤/查询信息列表 |

### 技术要求

| 要求 | 说明 |
|------|------|
| React 组件化 | 合理拆分组件，至少包含：App 根组件、列表组件、表单组件、搜索组件 |
| State 管理 | 使用 `useState` 管理数据状态 |
| 组件通信 | 父子组件之间通过 props 传递数据和回调函数 |
| 样式分离 | 样式写在 CSS 文件中，通过 `import` 引入 |

### 加分项（可选）

| 加分项 | 说明 |
|--------|------|
| 数据持久化 | 使用 `localStorage` 保存数据，刷新页面后数据不丢失 |
| 表单验证 | 添加/修改时验证必填字段，给出提示信息 |
| 分页功能 | 数据量较多时实现分页展示 |
| 排序功能 | 支持按某个字段排序 |
| 响应式布局 | 页面在不同屏幕尺寸下都能良好展示 |
| 拖拽排序 | 支持通过拖拽改变信息的顺序 |
| 登录验证 | 添加简单的登录界面，只有登录后才能访问信息管理系统 |

## 目录结构

```
项目根目录/
├── metadata.json        ← 【必填】填写你的姓名、学号、作业名称
├── package.json         ← 依赖配置
├── README.md            ← 本文件
├── Report.md            ← 作业报告（需填写）
├── index.html           ← 入口 HTML
├── vite.config.js       ← Vite 配置
├── eslint.config.js     ← ESLint 配置
├── src/                 ← 你的作业代码都写在这里
│   ├── main.jsx         ← 应用入口
│   ├── App.jsx          ← 根组件（已有注释引导）
│   ├── App.css          ← 根组件样式（已有注释引导）
│   ├── index.css        ← 全局样式
│   └── assets/          ← 静态资源目录（如需要）
├── public/              ← 公共资源目录
└── tool/
│   ├── check.cjs        ← 自检脚本
│   └── pack.cjs         ← 打包脚本
```

---

## 开始之前

### 1. 安装依赖

```bash
npm install
```

### 2. 填写个人信息

打开根目录的 `metadata.json`，填写你的信息：

```json
{
  "studentName": "张三",
  "studentId": "20240001",
  "assignmentName": "第三次作业"
}
```

### 3. 启动开发服务器

```bash
npm run dev
```

浏览器会自动打开开发页面，修改代码后页面会自动刷新（HMR）。

---

## 开发流程

1. 在 `src/App.jsx` 中编写根组件逻辑和布局
2. 根据需要在 `src/` 下创建子组件文件
3. 在 `src/App.css` 中编写样式
4. 如有图片资源放入 `src/assets/` 目录
5. 完成后撰写 `Report.md` 作业报告
6. 运行**自检脚本**，确认没有遗漏：

```bash
node tool/check.cjs
```

7. 自检全部通过后，运行**打包脚本**生成提交文件：

```bash
node tool/pack.cjs
```

打包完成后，会在根目录生成：

```
{学号}_{姓名}_{作业名称}.zip
```
